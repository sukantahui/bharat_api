Phase 1: Security & Authentication Hardening

P0 — CRITICAL

1.1 Configure Sanctum Token Expiration

config/sanctum.php:49

Tokens currently never expire ('expiration' => null). Set a default 30-day token lifetime via environment variables.

config/sanctum.php 
'expiration' => env('SANCTUM_EXPIRATION_MINUTES', 60 * 24 * 30), // 30 days

1.2 Dynamic CORS Whitelist from .env

config/cors.php:9

Prevent CORS blocks in staging and production by reading allowed origins dynamically from .env.

config/cors.php 
'allowed_origins' => explode(',', env('CORS_ALLOWED_ORIGINS', 'http://localhost:5173,http://127.0.0.1:5173')),

1.3 Add Rate Limiting to Sensitive Submission Routes

routes/api.php

Apply throttle:10,1 to student admissions and user registration to prevent automated spamming.

routes/api.php 
Route::post('admissionWithStudent', 'storeStudentWithAdmission')->middleware('throttle:10,1');
Route::post('/', 'register')->middleware('throttle:10,1');

1.4 Enforce Hidden Attributes & Mass Assignment Protection

app/Models/User.php

Ensure passwords and tokens never leak into JSON outputs and all Eloquent models use explicit $fillable arrays.

1.5 Unified JSON Exception Handling

bootstrap/app.php:29

Add explicit renderers for AuthenticationException and ValidationException to guarantee JSON error formatting.
